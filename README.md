# Gurur Orkun Ürensel — iOS Apps & Developer Website

Resmî geliştirici sitesi: **https://gururorkun.github.io/**

## 🌐 Public web yapısı

Bu repository'nin amacı uygulamalar için ortak, merkezi bir web adresi sağlamaktır:

```text
https://gururorkun.github.io/
├── app-ads.txt
├── varlik-takip/
│   ├── index.html
│   ├── support.html
│   └── privacy.html
└── chess-cards/
    ├── index.html
    ├── support.html
    └── privacy.html
```

### app-ads.txt

Reklam doğrulaması için kullanılan dosya:

**https://gururorkun.github.io/app-ads.txt**

Yeni uygulamalar aynı geliştirici web sitesini kullandığında, gerekli reklam yetkilendirme kayıtları bu ortak `app-ads.txt` dosyasında yönetilir.

> Uygulama kaynak kodları bu public repository'de bulunmaz.
